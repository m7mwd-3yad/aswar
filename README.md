# شركة اسوار الكنانة للمقاولات العامة
### الموقع الرسمي للشركة — فوم حجري حديث • جي ار سي GRC • بديل الحجر

موقع إلكتروني تعريفي حديث ومتجاوب لشركة **اسوار الكنانة للمقاولات العامة** المتخصصة في تكسيات وتشطيبات الواجهات الخارجية بالخرسانة المسلحة بالألياف الزجاجية (GRC)، الفوم الحجري الحديث، وبديل الحجر.
